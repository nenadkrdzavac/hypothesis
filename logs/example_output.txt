------------------------------------------------------------
Short introduction.
This file presents a few exact computations around the left factorial and Kurepa's hypothesis.
The aim is explanatory: each computation is accompanied by a brief mathematical interpretation.

By definition, !n is the sum of i! for 0 ≤ i < n.
These small values make the definition concrete.
For n = 0, the left factorial !n is 0.

For n = 3, we compute !n mod n = 1, so the residue is nonzero: yes.
For n = 5, we compute !n mod n = 4, so the residue is nonzero: yes.

Example 4: the recurrence viewpoint.
The recurrence ! (n + 1) = !n + n! lets us pass from one value to the next by adjoining a single factorial term.
A recurrence state means the current value !n together with the next term n! that will be added.
This viewpoint is useful because it suggests invariant properties that may later be proved formally.
Starting from !4 = 10 and 4! = 24,
the recurrence gives !5 = !4 + 4! = 10 + 24 = 34.
Interpretation: the recurrence packages the sequence into a step-by-step structure.
That structure is often the right place to look for congruences and invariants.

Closing summary.
We have seen the definition, several exact values, residues modulo n, a finite verification range, and the recurrence step.
These examples are relevant because they indicate patterns that may later be organized into lemmas, invariants, or a full proof.
The present file is a guided computational demonstration; it does not claim a proof of Kurepa's hypothesis.
